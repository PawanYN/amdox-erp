# Docs Index

| Folder          | What's in it                                                                                                                                                               |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `architecture/` | System design docs — backend/frontend architecture, auth flow, observability plan, RBAC matrix, logger design, monorepo structure blueprint-vs-reality                     |
| `audits/`       | Point-in-time audit reports and compliance checks — TDD compliance, containerization, security hardening, wiring, DB read-replica strategy, known codebase inconsistencies |
| `planning/`     | Task tracking and status — implementation task list, live project status, team assignment/session log, frontend-backend wiring plan                                        |
| `guides/`       | How-to / setup docs — running the frontend standalone, BI installation & recovery, company-A demo login list                                                               |
| `reference/`    | Static reference material — the original TDD PDF, a free-alternatives-to-paid-services note, an HR Postman collection, a detailed HTML writeup                             |
| `adr/`          | Architecture Decision Records                                                                                                                                              |
| `api/`          | OpenAPI spec                                                                                                                                                               |
| `c4/`           | Mermaid-based C4 diagrams (Context/Container/Component) — an earlier, markdown-based companion to the team's Eraser diagrams                                               |
| `erd/`          | Generated database ERD (image + markdown + Graphviz source)                                                                                                                |
| `learning/`     | Day-by-day concept walkthroughs written while building specific features                                                                                                   |
| `fixtures/`     | Sample files used in tests (e.g. sample invoices)                                                                                                                          |
| `doubts/`       | Open questions about specific business rules                                                                                                                               |
| `images/`       | A single unreferenced screenshot (kept as-is, not worth its own rule)                                                                                                      |
